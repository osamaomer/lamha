# Phase 1's screen designs

The six screens of Lamha 3, as signed off by the user on 2026-10-25. Each page opens in a browser (on Windows, at 100 % zoom: the sizes are the real ones, and the fonts are Windows'), with switches for Arabic or English and light or dark. They are drawn with the design tokens in `src/Lamha.App/Themes/Tokens.xaml`. Phase 4 builds the windows from them; what was decided for each, and the new wording approved, is in the plan's *Phase 1 progress* ([native-plan.md](../native-plan.md)).
